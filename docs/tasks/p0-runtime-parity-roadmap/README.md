# P0 Runtime Parity Roadmap

Date: 2026-04-26

## Purpose

This folder defines the P0 roadmap for moving `myclaw` from a runnable Claude Code-style runtime toward a behaviorally aligned runtime core.

This is a planning and sequencing task, not a direct implementation module.

## Read Order

1. `task.md`
2. `design.md`
3. `source-alignment.md`
4. `implementation-plan.md`
5. `test-validation-plan.md`
6. `review-checklist.md`

## Roadmap Outcome

After this roadmap is accepted, P0 implementation should proceed through separate implementation task folders for:

1. `p0-tool-parity-core`
2. `p0-command-registry`
3. `p0-context-memory-recovery`
4. `p0-runtime-structured-events`

The roadmap is complete when those downstream task folders can be created without re-debating P0 scope.
