# P0 Tool Parity Core Review Checklist

- [ ] Core tools have stable input schema and metadata.
- [ ] Core tools have read-only/destructive classification tests.
- [ ] Permission and approval paths are conservative and observable.
- [ ] Tool-use and tool-result identity is preserved.
- [ ] Tool failures produce model-consumable error results.
- [ ] QueryEngine and runtime consume the same tool contract.
- [ ] Focused workstream tests pass.
